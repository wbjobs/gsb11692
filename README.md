# 流体 / 烟雾模拟 (Stable Fluids)

基于网格的 Navier-Stokes 简化求解器（Jos Stam "Stable Fluids"），
Canvas + WebGL + Web Worker + PerformanceObserver + TypedArray 实现。

## 运行

```bash
# ES module + Worker 需要 HTTP 环境
python3 -m http.server 8000
# 打开 http://localhost:8000
```

## 测试与基准

```bash
node test/stability.test.mjs   # 稳定性 / 边界条件 / 大网格
node test/benchmark.mjs        # 分辨率 vs 性能对照
```

## 架构

```
主线程  main.js      UI / 交互采样 / FPS 统计 / 自动降级
  │  splat·params·resize (postMessage, 每帧批量)
  ▼
Worker  worker.js    固定步长模拟循环 (accumulator, ≤2 子步, 防死亡螺旋)
  │  solver.js       TypedArray 双缓冲求解器 (与 Node 测试共享同一文件)
  │  Uint8 密度帧 (Transferable, 双缓冲回收, 零逐帧分配)
  ▼
主线程  renderer.js  WebGL 纹理 + inferno 伪彩色 shader (降级 Canvas 2D)
```

## 数值稳定性设计

- **半拉格朗日平流**：无条件稳定，回溯坐标钳制在网格内，dt 超 CFL 也不爆炸（有测试覆盖 dt=0.1）。
- **隐式扩散**：Gauss-Seidel 求解 `(I - dt·diff·∇²)x = x0`，任意扩散系数稳定。
- **压力投影**：Helmholtz-Hodge 分解保证无散度；每帧投影两次（扩散后、平流后）。
- **时间积分**：固定步长 1/60 + accumulator，最多 2 子步，跟不上就丢时间而不是追帧（防"死亡螺旋"）。
- **帧间隔钳制**：切后台回来 dt 上限 50ms。
- **输入钳制**：splat 力/染料有上限，密度钳制到 [0, 8]。
- 已知取舍：Gauss-Seidel 对低频误差每步只衰减 `~(1-(π/N)²)`，大网格下 20 次迭代
  只能部分收敛（Stam 原算法同样如此）。视觉上无影响（高频散度被快速消除），
  测试中用 N=32 + 200 迭代验证投影算子本身的正确性。

## 边界条件

四周固体墙（`solver.js` 的 `setBnd`）：

- 速度法向分量在墙面镜像取反（无穿透）；
- 密度/压力等标量在墙面镜像（零法向梯度）；
- 角点取两邻点平均，避免奇异。

测试逐格验证 `u[0,j] === -u[1,j]` 等不变量。

## 分辨率与性能取舍（实测，Node 22）

| 网格 | 内存 | 平均步耗时 | 理论 FPS 上限 |
|------|--------|-----------|--------------|
| 64   | 0.15 MB | 1.4 ms  | ~729 |
| 96   | 0.33 MB | 3.1 ms  | ~319 |
| 128  | 0.58 MB | 5.8 ms  | ~172 |
| 192  | 1.29 MB | 13.4 ms | ~74  |
| 256  | 2.29 MB | 23.5 ms | ~42  |
| 384  | 5.12 MB | 53.7 ms | ~18  |

结论：128–192 是 60 FPS 的甜区；256 以上单步已超 16.7ms 预算，
适合静态画质展示。UI 面板实时显示 FPS / 单步耗时 / 网格规模 / 内存，可直接对照。

## 大网格内存

- 9 个 `Float32Array((N+2)²)` 常驻（双缓冲速度/密度 + 压力/散度/涡度），
  N=384 时约 5MB，无 GC 压力；N 上限硬编码 512（约 9.5MB），非法规模直接抛错。
- 帧传输用 2 块可转移 `Uint8Array(N²)` 循环：Worker 发出后主线程渲染完归还，
  全程零逐帧分配；Worker 侧无可用缓冲时跳帧（背压保护）。

## 交互延迟

- `pointermove` 采样后沿路径插值成 splat 入队，每帧合并为一批消息发给 Worker，
  避免消息洪泛；
- 模拟在 Worker 线程，主线程拖动不会被求解阻塞；
- 主线程若一帧内收到多帧模拟结果，直接丢弃旧帧归还缓冲（保延迟不保帧数）。

## 降级策略

1. **自动降分辨率**：FPS(EMA) 连续 2 秒低于 45 且开启"自动降级"时，
   沿 256→192→128→96→64 降一档（只降不升，避免来回抖动），面板显示降级提示。
2. **渲染降级**：WebGL 不可用时自动切 Canvas 2D（`putImageData` + 平滑缩放），
   面板"渲染后端"一栏可见当前模式。
3. **时间降级**：Worker 单帧跟不上固定步长时丢时间而非累积，保证响应性。

## 验收标准对照

| 标准 | 实现 / 验证 |
|------|------------|
| 模拟稳定不爆炸 | 半拉格朗日 + 隐式扩散 + 投影；测试含 600 步随机强扰动、超 CFL dt |
| 交互响应正确 | pointer 拖动 → 路径插值 splat；Worker 模拟不阻塞 UI |
| 分辨率和性能对照可量化 | `test/benchmark.mjs` 输出表格；UI 实时显示 FPS/步耗时/网格/内存 |
| 边界条件正确 | 固体墙 `setBnd`，测试逐格验证镜像/取反不变量 |
| 大网格不崩 | 测试覆盖 256/384；TypedArray 常驻 ~5MB；N 上限 512 硬校验 |
